# Educoder 答案导入导出（JavaScript 油猴脚本）

在 Tampermonkey 中新建脚本，将 `educoder-answers.user.js` 全部内容粘贴进去，保存启用，然后刷新关卡页面。右下角显示“答案导入 / 导出”。脚本需在页面环境、页面请求前运行；若始终未读取，请检查扩展访问权限和启用状态。

## 导出

打开已作答的选择题关卡并刷新，点击“导出当前答案”。下载文件只包含当前关卡按题号排列的答案数组，例如：

```json
["B", "C"]
```

不导出题干、选项、账号或任务 ID，不判断答案正确性。答案直接来自任务详情中的 `choose_test_cases.test_sets[].actual_output`，重新提交时也会从提交响应更新。仅支持当前关卡的完整选择题答案，多选答案字符串原样保留。每个关卡分别导出，文件自动命名为“关卡名称.json”（例如“欠拟合与过拟合.json”），不适合文件名的字符会自动替换。没有自动遍历全部作业。

## 导入

1. 打开对应关卡并刷新，等待选择题加载完成。
2. 点击“导入答案”，选择 JSON 文件，脚本直接更新页面上的单选和多选。
3. 看到“已更新”后，可自行修改选择，再使用平台提交按钮提交。

浮窗标题栏支持鼠标或触屏拖动，拖动范围限制在窗口内；点击标题可折叠。没有答案预览或额外应用按钮。

答案按题目与选项顺序回填，因此双方顺序必须一致。导入会取消多选题原有的多余选项。脚本通过原生点击触发页面 change 处理，并在回填后核对控件状态；不修改提交请求。若控件未识别、答案越界或题目数量不符，会显示错误。操作中失败可能已有部分选项更新，请检查页面。

当前适配标准 input 单选、多选以及 Ant Design 分组。尚未拿到真实头歌页面的选项 HTML，实际页面如采用其他控件，需要提供一道题的外层 HTML 进一步适配。导出格式仍只有答案字符串数组。
